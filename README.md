# Ascendent Realms

An online 3D adventure game where you play as a non-human race (Elf, Dwarf, Hobbit, Giant, Beastkin) or a monster (Goblin, Slime, Fairy, Lizardman, Naga, Dragonewt), pick a class, and rise through the ranks. Only one character per server can become King.

The game rules (stats, races, classes, EXP curve, ranks and what to do at each level) live in the [rulebook](https://claude.ai/artifact/5W41YpdbF9RZxh5QqMy76s).

## Running it on your computer

1. Install [Node.js](https://nodejs.org) version 22.5 or newer.
2. In this folder, run `npm install`.
3. Run `npm start`.
4. Open http://localhost:3000 in your browser.

Accounts are stored in `data/game.db`, which is created the first time the server starts.
